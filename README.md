# 💬 ApertureChat v1.0 (Автономный LAN-мессенджер)

**ApertureChat** — это легковесный, полностью автономный мессенджер для общения внутри локальной сети (Wi-Fi или Ethernet), разработанный на чистой Java (Swing). Программа не требует подключения к интернету, внешних серверов или баз данных. Обмен сообщениями происходит напрямую между компьютерами по протоколу TCP/IP (Sockets).

## 🛠️ Основные возможности

* **Полная автономность** — работает в изолированных локальных сетях без доступа к глобальному интернету.
* **Два режима работы** — приложение совмещает в себе функции как сервера (для ожидания подключений), так и клиента.
* **Многопоточный движок** — фоновое чтение сокетов гарантирует мгновенную доставку сообщений без зависания графического интерфейса.
* **Портативность** — интерфейс построен на стандартной библиотеке Java Swing, что обеспечивает полную кроссплатформенность (Windows, macOS, Linux).

## 📦 Инструкция по запуску и тестированию

Для проверки связи на одном компьютере или в домашней сети:

1. Скачайте исходный файл `ApertureChat.java` или готовый собранный архив `ApertureChat.jar`.
2. Запустите две копии приложения:
   * **На первом окне (Сервер):** Оставьте стандартный порт `7777` и нажмите кнопку **"Создать Сервер"**.
   * **На втором окне (Клиент):** Укажите IP-адрес `127.0.0.1` (для локального теста на одном ПК) или реальный IP-адрес сервера в домашней сети, после чего нажмите кнопку **"Подключиться"**.
3. После успешного сопряжения каналов текстовые поля разблокируются для двустороннего обмена сообщениями.

## ⚙️ Компиляция и сборка

Сборка проекта из исходного кода выполняется стандартными средствами JDK:

* Компиляция исходника:
  ```bash
  javac ApertureChat.java
  ```
* Упаковка в автономный исполняемый JAR-архив:
  ```bash
  jar cfe ApertureChat.jar ApertureChat *.class
  ```
